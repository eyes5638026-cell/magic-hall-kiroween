# Development provenance

## Original implementation — 2026-11-17

The project owner's existing development record documents the first Magic Hall implementation on November 17, 2026. Kiro designed and wrote the interface. A separate Codex task supplied its original background artwork. The original interaction was:

- floating gold candles reveal pictures;
- floating blue candles play music;
- a work can open the conversation that inspired it;
- the experience is a place to revisit creations rather than a folder list.

The original implementation was a working personal gallery. Its personal content, index builder, service paths, identity details, original assets and repository history are not part of this public repository.

## Public adaptation — 2026-11-20

Prepared by **ChatGPT/Codex** under the project owner's explicit instruction to prepare a shareable Kiroween submission while keeping the personal art library private.

The adaptation continues the original candle-depth placement, pre-rendered glow-sprite rendering and audio-response approach. It replaces private integrations with a self-contained fictional collection and adds an accessible collection list, semantic candle controls, native dialogs, bilingual text, local synthesized music, controllable motion and static hosting.

## `.kiro` chronology

The original inspected repository did not contain a project-root `.kiro/` directory. The public edition's `.kiro/steering/` and `.kiro/specs/public-demo/` documents were prepared on **2026-11-20 by ChatGPT/Codex** as current project instructions and a public-edition specification. They are not reconstructed historical Kiro files and do not claim to be generated by Kiro.

## Reuse disclosure

This is a public adaptation of a Magic Hall implementation begun during the competition period, not a submission of an older archive system. The application code's interaction design is derived from the November 17 version. All demonstration content in this repository was created for this edition; no private archive backend is required or included. There are no runtime third-party libraries.
