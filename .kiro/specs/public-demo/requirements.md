# Requirements — public demo

Prepared 2026-11-20 by ChatGPT/Codex as the current public-edition spec. See `docs/DEVELOPMENT.md` for original Kiro work and accurate chronology.

1. When a visitor enters the hall, the interface shall reveal an explorable field of gold and blue candles and start music only after that visitor action.
2. When the visitor activates a gold candle, the interface shall show its artwork, title, description and source-story action.
3. When the visitor activates a blue candle, the interface shall play its local original score and display pause, mute and source-story controls.
4. When a source action is selected, the interface shall open the corresponding fictional conversation without leaving the hall.
5. The collection shall also be navigable through ordinary keyboard-reachable controls and a complete list.
6. The public edition shall work on desktop and narrow mobile screens, with English default and an optional Chinese interface.
7. Motion shall respect the visitor's operating-system preference and manual atmosphere control.
8. The distributable shall contain only this edition's fictional demonstration data and public licensed assets, with no personal archive dependency.
9. The project shall run from a static HTTP server without a build, external runtime dependencies or credentials.
10. Development provenance shall distinguish the November 17 Kiro implementation from the November 20 public adaptation and shall not fabricate historical work.
